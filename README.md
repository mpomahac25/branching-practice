# Git Branching Workshop

A shared practice repository for two collaborators learning Git branches, pull requests, branching strategies, and merge conflicts.

## Team rules

- Work on your own feature branch instead of committing directly to `main`.
- Open pull requests against `main`.
- Read your partner's changes before merging.
- Follow the workshop slides for the exercises.

## Starting files

- `README.md` — description of the practice repository.
- `team-notes.md` — shared line used in the merge-conflict exercise.

Start by cloning the repository on each student's computer.
